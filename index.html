ABEFLIX Documentation Portal

Welcome to the official technical documentation for ABEFLIX, the ultimate Netflix-inspired streaming theme built specifically for Google Blogger / Blogspot.

?? What makes ABEFLIX unique?
Unlike typical templates requiring deep code edits, ABEFLIX uses a modular {lazyPosts} widget shortcode engine, automated "Continue Watching" playback persistence, and full user accounts (Watchlist, Favorites, History, Avatars).

1. Installation Guide

  1. Go to your Blogger Dashboard > Theme tab.
  2. Click the arrow next to Customize and select Edit HTML.
  3. Backup your existing code, select all, and paste the contents of your licensed ABEFLIX Original.xml.
  4. Click Save.

3. Required Core Pages

Create these standalone Blogger pages (via Pages > New Page) or import feed.atom:

  • Favorite — URL: /p/favorite.html
  • History — URL: /p/history.html
  • Watchlist — URL: /p/watchlist.html
  • My Account — URL: /p/my-account.html
  • Leaderboard — URL: /p/leaderboard.html
  • Discover — URL: /p/discover.html

4. Shortcode Engine (`{lazyPosts}`)

Add an HTML/JavaScript Gadget anywhere in your layout (e.g. Main Homepage Rail) and paste a shortcode:

{lazyPosts} $label={Action} $results={12} $style={nowrap} $class={carousel-posts}

5. Video Multi-Server Player

In your post HTML editor, format video streaming servers easily:

<div id="player-servers">
  <button data-stream="https://server1.example/embed/xyz">Server 1 (FHD)</button>
  <button data-stream="https://server2.example/embed/xyz">Server 2 (Backup)</button>
</div>

6. User Dashboard & Engagement Features

  • Watchlist & History: Automatically synced in the viewer's local browser storage.
  • Continue Watching: Progress timestamps saved whenever a video is paused or exited.
  • Avatar Packs: Built-in picker under "My Account" with anime & cinema themed avatars.
