ABEFLIX Theme Documentation

Welcome to the official technical documentation for the ABEFLIX Blogger streaming theme. This comprehensive manual guides you through initial setup, layout configuration, post formatting, shortcode widgets, and user account management to help you launch a high-traffic OTT streaming web app.

?? Why ABEFLIX?
ABEFLIX turns Blogger into a true web app with a modular {lazyPosts} shortcode layout engine, automated Continue Watching playback resume, dynamic leaderboards, categorized avatar packs, and a multi-source video player.

1. Initial Setup

a. Creating Required Static Pages

ABEFLIX uses dedicated static pages for Watchlist, History, Favorites, Discover, My Account, and Leaderboards. Create each page inside your Blogger dashboard:

  1. Go to Pages > New Page.
  2. Enter the exact required title (e.g. Watchlist).
  3. Leave the page content area completely blank and click Publish.
  4. Repeat this process for all core pages:
    • Watchlist — URL: /p/watchlist.html
    • Favorite — URL: /p/favorite.html
    • History — URL: /p/history.html
    • Discover — URL: /p/discover.html
    • My Account — URL: /p/my-account.html
    • Leaderboard — URL: /p/leaderboard.html
?? Important: Keep Pages Blank
Do not write HTML or import code into these pages. The theme's built-in script automatically recognizes the page URL slug and renders the appropriate interactive interface (watch history, watchlist cards, avatar selection, etc.).

b. General Blogger Settings

  • Favicon: Navigate to Settings > Basic > Favicon and upload a square PNG or ICO icon.
  • Time Zone: Navigate to Settings > Formatting and set your target timezone.

2. Layout Guide & Widget Configuration

Every element on the homepage and watch page is modularly arranged in your Layout dashboard.

a. Header Widgets

  • DESKTOP MENU - MAIN LINK: Contains two Link List gadgets controlling top-level desktop header navigation.
  • DESKTOP HEADER WIDGET: Houses Search, History, Watchlist, and User Account action buttons. Works out-of-the-box without manual configuration.
  • MOBILE LOGO, SEARCH, NAVIGATION: Three dedicated sections for mobile viewports. Edit the Image gadget for the mobile logo and the Link List gadget for mobile drawer navigation.

b. Desktop Sidebar Navigation

  • ABEFLIX (Image): The primary desktop sidebar logo.
  • Main Navigation (Link List): Main navigation shortcuts (Home, Movie, TV Series, Animation, Discover, etc.).
  • Theme Settings (HTML/JavaScript): Toggles the client-side color swatch customizer and dark/light modes.
  • Download App (HTML/JavaScript): Displays the QR code and Android APK download prompt. Add your direct APK link here.
  • Follow Us (HTML/JavaScript): Social media channels (Telegram, Twitter/X, Discord, Instagram).

c. Homepage Content Widgets

Use Blogger HTML/JavaScript gadgets with {lazyPosts} shortcodes to build custom feeds, sliders, and ranked grids.

PAGE BODY Section

  • Trending Now (Popular Posts): Built-in widget automatically pulling the Top 10 most viewed titles over the last 7 days.
  • Continue Watching (HTML/JavaScript): Displays the viewer's active playback rail automatically if in-progress titles exist in local storage.

3. Modular Shortcode Engine (`{lazyPosts}`)

The {lazyPosts} engine allows you to specify label filtering, result limits, sorting methods, and layout styling directly:

  • Horizontal Carousel (nowrap): 
    {lazyPosts} $label={Movie} $results={12} $style={nowrap}
  • Responsive Grid (grid): 
    {lazyPosts} $label={Thriller} $results={6} $style={grid}
  • Ranked Wide List (wide-list): 
    {lazyPosts} $label={TV Series} $results={9} $style={wide-list} $sortBy={rating}
  • Alternate Ranked Grid (ranked-grid-alt): 
    {lazyPosts} $label={Movie} $results={9} $style={ranked-grid-alt} $sortBy={rating}
  • Filtered Switch Grid (filtered-switch):

    Pulls random posts across comma-separated labels. Clicking "Switch" instantly re-rolls a new random selection.

    {lazyPosts} $label={Romance,Comedy} $results={6} $style={filtered-switch}

Celebrity & Upcoming Carousels

4. Creating a Post (The Right Way)

To enable the multi-server video player, backdrop slider, metadata tags, download links, and cast cards, write posts in HTML view using the exact structure below:

  1. Go to Posts > New Post.
  2. Switch the editor toolbar from "Compose view" to "HTML view".
  3. Paste the template below and replace placeholder fields:
<!-- 1. Backdrop Image for Banner / Hero -->
<span class="slider-backdrop" style="display:none;">https://example.com/backdrop.jpg</span>

<div>
  <!-- 2. Poster Image (Standard Thumbnail) -->
  <img alt="poster" src="https://example.com/poster.jpg" />

  <!-- 3. Main Video Iframe (Default Fallback Embed) -->
  <iframe class="lazyloaded" data-src="/" src="/" allowfullscreen="true"></iframe>

  <!-- 4. Synopsis / Overview -->
  <p class="overview" id="overview-data">This is the synopsis description of the movie or television show.</p>
</div>

<!-- 5. METADATA (Hidden) -->
<div id="extra-meta" style="display:none;">
  <span class="meta-title-logo">https://example.com/title-logo.png</span>
  <span class="meta-pg">TV-MA</span>
  <span class="meta-country">Japan</span>
  <span class="meta-genre">Animation</span>
  <span class="meta-genre">Comedy</span>
  <span class="meta-year">2026</span>
  <span class="meta-rating">8.4</span>

</div>

<!-- 6. Multi-Server Video Episodes / Stream Hosts -->

Post Labels & Safe Mode

??? Crucial Post Labels
In the Post Settings sidebar, assign labels like Action, Movie, TV Series, or Drama.

Safe Mode Trigger: To flag a post as 18+ or mature, simply add the label Mature. When viewers activate the Safe Mode toggle, all posts with this label are instantly hidden.

5. User System & Custom Avatars

The My Account page (/p/my-account.html) acts as the visitor profile center. Viewers can edit their display username, switch avatars, and inspect their Watchlist and History records.

Configuring Avatar Packs (Admin)

  1. Open your Blogger Layout dashboard.
  2. Locate the section labeled Avatar Data Source.
  3. Add Avatar Categories: Open the Link List widget titled "Avatar Categories". Add a link for each desired pack (e.g. Name: Anime, URL: #).
  4. Add Avatars to Category: For each category, open the corresponding gadget, click Add a Gadget > Image, and upload avatar images.

6. Notification System

Broadcast alerts and announcements directly to the header bell icon with active badge counters:

  1. Go to Layout > Notifications.
  2. Click Add a Gadget > HTML/JavaScript.
  3. Leave the title blank and paste one of the notification formats:

Format 1: System Message

<div class="noti-item">
  <div class="noti-content">
    <div class="noti-main">System update: New high-speed streaming server added.</div>
    <div class="noti-sub">System Message ? Oct 28, 2026</div>
  </div>
</div>

Format 2: Announcement with Image

<div class="noti-item">
  <div class="noti-content">
    <div class="noti-main">
      <span class="text-highlight">New Release!</span> Season 2 is now available to stream.
    </div>
    <div class="noti-sub">ABEFLIX ? Oct 28, 2026</div>
  </div>
  <div class="noti-icon">
    <img src="https://example.com/notice-icon.png" loading="lazy" alt="Avatar"/>
  </div>
</div>

7. Interactive Features & Customization

  • Star Ratings & Reactions: Real-time ratings and emoji reactions are powered by a client-side Supabase database connection and work out-of-the-box.
  • Comment Formatting Helper: Post pages feature a dedicated formatting helper for visitors to easily create formatted comments (bold, quotes, code blocks).
  • Theme Customizer: Users can choose between light/dark modes and select 12+ vibrant accent color palettes via the floating Theme switcher in the sidebar.
